# Kright — форк з автовиправленням UA ↔ EN

Форк [Kright](https://github.com/walteryaron/Kright) (MIT, Yaron Walter) для Windows.
Оригінал виправляє розкладку лише за хоткеєм; тут додано автоматику та решту функцій.

## Що додано

- **Автовиправлення** на пробілі, Tab, Enter. Гібрид: частотні словники (40 тис. UA + 40 тис. EN)
  вирішують, коли слово відоме; біграмна модель Kright — лише для рідкісних слів і зі строгішим порогом.
- **Короткі слова перед виправленим**: `z ghbdsn` → `я привіт`, а не `z привіт`.
- **Скасування**: Backspace одразу після заміни повертає набране, і слово потрапляє в «Ніколи не виправляти».
- **Навчання на хоткеї**: слово, двічі виправлене через `Ctrl+Alt+K`, потрапляє в «Завжди виправляти».
- **Мій словник**: два списки в Налаштуваннях. Можна додати кілька слів одразу, через кому.
- **Програми-виключення**: кнопка «Виключити поточну програму». За замовчуванням виключені термінали, VS Code, Visual Studio і менеджери паролів.
- **Англійська в адресному рядку** браузера: Chrome, Edge, Brave, Opera, Vivaldi, Firefox.
- **Поля паролів**: автовиправлення вимикається, поки курсор у такому полі.
- **Запуск разом з Windows**: чекбокс у Налаштуваннях.
- **Захист від подвійного запуску**: друга копія одразу закривається.
- **Пауза**: пункт «Автовиправлення» в меню трею.
- **Інтерфейс** українською.

Не виправляються: слова КАПСОМ (абревіатури), слова з великою літерою всередині (iPhone),
слова з цифрами, а також текст після Ctrl-комбінацій, стрілок чи Delete до наступного пробілу.

## Збірка

1. Встановіть .NET 8 SDK: `winget install Microsoft.DotNet.SDK.8`
2. Запустіть `build-ua.cmd`. Він прожене тести й збере один файл `publish-ua\Kright.exe`.
3. Перед першим запуском закрийте оригінальний Kright (трей → Quit) і видаліть його,
   щоб не працювали дві копії з одним хоткеєм.

Налаштування спільні з оригіналом: `%APPDATA%\Kright\settings.json`.

## Перевірка якості детектора

Ганявся на 230 тис. випадків: 60 тис. найчастіших слів кожної мови,
набраних правильно та не в тій розкладці.

| | Виправлено, коли треба | Зіпсовано правильне слово |
|---|---|---|
| Слова зі словника | 95% слів (87% з урахуванням частоти) | 0,05% (0,011% з урахуванням частоти) |
| Рідкісні слова поза словником | 77% | 0,13% |

Найчастіше хибно спрацьовують двобуквені пари, які є словами в обох мовах (`ps` → `зі`).
Такі слова додайте в «Ніколи не виправляти» або скасуйте Backspace — програма запам'ятає.

## Оновлення вимкнені

Вбудований апдейтер оригіналу замінив би цю збірку офіційною, тому перевірку оновлень вимкнено.
