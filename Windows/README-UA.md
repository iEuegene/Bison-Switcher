# Bison Switcher (BS)

Автоперемикач і автовиправлення розкладки UA ↔ EN для Windows.

Зроблено на основі [Kright](https://github.com/walteryaron/Kright) (MIT, Yaron Walter).
Оригінал виправляє розкладку лише за хоткеєм; тут додано автоматику та решту функцій.

## Що додано

- **Автовиправлення** на пробілі, Tab, Enter. Гібрид: частотні словники (≈280 тис. словоформ UA, ≈190 тис. EN)
  вирішують, коли слово відоме; біграмна модель Kright — лише для рідкісних слів і зі строгішим порогом.
- **Велика літера на початку речення**: після `. ! ?` і пробілу (скорочення на кшталт «грн.», «т. д.» і три крапки не враховуються).
- **Короткі слова перед виправленим**: `z ghbdsn` → `я привіт`, а не `z привіт`.
- **Скасування**: хоткей `Ctrl+Alt+K` одразу після заміни (поки не почато наступне слово) повертає набране, і слово потрапляє в «Не виправляти». Backspace більше не скасовує — він просто стирає символ.
- **Плавна прокрутка** (`Services/SmoothScroller.cs`, `ScrollPhysics.cs`): клік коліщатка розкладається на дрібні кроки з плавним гальмуванням. Хук миші лише вирішує й ставить у чергу, рух генерує окремий потік. Пропускаються без змін: коліщатка з високою точністю, Ctrl/Alt + коліщатко, ігри (бібліотеки лаунчерів + список ігор Windows `GameConfigStore`), програми зі списку, адмін-вікна. LibreOffice Calc — рядок за рядком, три способи подачі рядка на вибір (A/B/C) для перевірки.
- **Режим адміністратора**: завдання Планувальника «при вході, найвищі права» — BS працює і в адмін-вікнах без UAC при кожному запуску.
- **Сторож хуків**: кожні 30 с хуки клавіатури й миші перевстановлюються — Windows мовчки знімає хук, який хоч раз загальмував.
- **Навчання на хоткеї**: слово, двічі виправлене через `Ctrl+Alt+K`, потрапляє в «Навчити нових слів».
- **Мій словник**: два списки в Налаштуваннях. Можна додати кілька слів одразу, через кому.
- **Програми-виключення**: кнопка «Виключити поточну програму». За замовчуванням виключені термінали, VS Code, Visual Studio і менеджери паролів.
- **Англійська в адресному рядку** браузера: Chrome, Edge, Brave, Opera, Vivaldi, Firefox.
- **Поля паролів**: автовиправлення вимикається, поки курсор у такому полі.
- **Запуск разом з Windows**: чекбокс у Налаштуваннях.
- **Захист від подвійного запуску**: друга копія одразу закривається.
- **Пауза**: пункт «Автовиправлення» в меню трею.
- **Інтерфейс** українською, у фірмовому стилі Inweb: бокова навігація, сторінки Огляд / Автовиправлення / Словник / Програми / Розкладка / Прокрутка / Система.

Не виправляються: слова КАПСОМ (абревіатури), слова з великою літерою всередині (iPhone),
слова з цифрами, а також текст після Ctrl-комбінацій, стрілок чи Delete до наступного пробілу.

## Збірка

1. Встановіть .NET 8 SDK: `winget install Microsoft.DotNet.SDK.8`
2. Запустіть `build-ua.cmd`. Він прожене тести й збере один файл `publish-ua\BisonSwitcher.exe`.
3. Перед першим запуском закрийте оригінальний Kright (трей → Quit) і видаліть його,
   щоб не працювали дві копії з одним хоткеєм.

Налаштування: `%APPDATA%\BisonSwitcher\settings.json`. При першому запуску підтягуються налаштування Kright, якщо вони є.

## Перевірка якості детектора

Ганявся на 320 тис. випадків: 60 тис. найчастіших слів кожної мови плюс 20 тис. рідкісних
словоформ, набраних правильно та не в тій розкладці.

| | Виправлено, коли треба | Зіпсовано правильне слово |
|---|---|---|
| Українські слова, набрані на EN (топ-60 тис.) | 96,9% | 0,04% |
| Англійські слова, набрані на UA (топ-60 тис.) | 93,1% | 0,09% |
| Рідкісні українські словоформи | 97,8% | 0,04% |

Найчастіше хибно спрацьовують двобуквені пари, які є словами в обох мовах (`ps` → `зі`).
Такі слова додайте в «Не виправляти» або скасуйте хоткеєм одразу після заміни — програма запам'ятає.
Однобуквені слова (`в`, `і`, `у`, `я`) окремо не виправляються — лише разом із наступним словом.

## Оновлення

Програма раз на день перевіряє GitHub Releases цього репозиторію (`/releases/latest`) і пропонує оновитися: інсталятор завантажується й запускається тихо. Вбудований апдейтер оригінального Kright (NetSparkle) вимкнено, щоб він не замінив цю збірку.
